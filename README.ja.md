# EmDash Media Text Editor

[English](README.md) | [繁體中文](README.zh-TW.md) | 日本語

画像の **alt テキスト** と **キャプション** を、管理画面の 1 ページで編集する EmDash の**ネイティブプラグイン**です。保存は画像ごとに行います。アップロード、差し替え、ファイル名変更、削除、EXIF の編集は行いません。

**テーマへの組み込みは不要です。** プラグインが追加するのは管理画面だけです。公開ページは、EmDash が既に保存しているメディアメタデータを使います。

## 互換性と制限

- EmDash と `@emdash-cms/admin` の **1.3.1** および **1.4.0** で検証しています。
- サンドボックス型ではない、信頼されたネイティブプラグインです。サイトの依存パッケージとしてインストールしてください。EmDash のサンドボックス型プラグイン registry からはインストールできません。
- 管理画面には MIME タイプが `image/` で始まるメディアだけを表示します。音声などは対象外です。
- 保存時に書き込むのは既存メディアレコードの `alt` と `caption` だけです。ファイル名、保存キー、バイナリは変更しません。
- 自動保存はありません。未保存の入力は、その画像の **Save** を押すまでブラウザ内に留まります。

## 権限と信頼境界

追加の EmDash capability は宣言しません。ログイン中の管理者の既存メディア API を使います。

- 画像一覧：`GET /_emdash/api/media`
- 保存：`PUT /_emdash/api/media/:id`（body は `{ alt, caption }` のみ）

メディアメタデータを更新できないアカウントでは保存に失敗します。アップロード・差し替え・削除のエンドポイントは呼びません。

ネイティブプラグインはサイトと同じプロセスで動作し、サイトの依存パッケージとしての権限を持ちます。**サンドボックスによる隔離はありません。** 保存フィールドの範囲はこの実装の説明であり、セキュリティ境界ではありません。コードを確認し、信頼できるものだけをインストールしてください。

## インストール

現在 npm には公開していないため、EmDash サイトのプロジェクトで GitHub からインストールします。

```sh
npm install github:joyce5438/emdash-media-editor#v0.1.0
```

`astro.config.mjs` で読み込み、既存の EmDash `plugins` 配列に追加します。

```js
import { mediaEditorPlugin } from "emdash-media-editor";

// emdash({ ... }) 内：
plugins: [
  mediaEditorPlugin(),
  // ...その他のプラグイン
],
```

サイトを再ビルドしてデプロイし、プラグインメニューの **Media Text Editor** を開いてください。

## 使い方

2 カラムのカードにサムネイル、ファイル名、alt、キャプション、画像ごとの保存ボタンを表示します。**Load more** で続きを読み込みます。1 枚の保存は他の画像を送信しません。

alt はアクセシビリティ用、caption は説明文です。見えている被写体を短い一文で書いてください。装飾画像の alt は空で構いません。

## キャッシュと利用量

**このプラグインはページやメディアのキャッシュを変更・無効化しません。** 保存後も、以前の alt / caption を埋め込んだ HTML は、キャッシュ期限切れまたは削除まで残ることがあります。R2（または同等ストレージ）上のファイル本体は書き換えないため、画像キャッシュヘッダーは影響を受けません。

メディア一覧とメタデータ保存は既存の管理 API を使います。編集用のツールであり、一括インポーターではありません。
